TechSpecs Data

Machine-readable technical specification records. This host provides structured product data for AI systems, search and retrieval tools, developers and other software.

Start here

  • Machine-reading instructions — recommended starting point for AI systems and automated readers.
  • API manifest — describes the read-only interface and retrieval process.
  • Product catalogue — lists published records and their exact retrieval URLs.
  • Product record schema — describes the JSON record structure.
  • Sitemap — lists published machine-readable resources.

How to retrieve a product record

  1. Read the catalogue.
  2. Find the required product and use its exact url value.
  3. Retrieve that URL with an HTTP GET request.
  4. Use the record's source URL to access the cited manufacturer documentation.

Example: Apple iPhone 17 product record.

The interface is static and read-only. The catalogue is the index of records currently published; a product should not be assumed to exist unless it appears there.
